Security

Ubahin processes files in your browser using JavaScript and WebAssembly. This means your files are not sent to our servers.

What is loaded from the internet

  • Pages, styles, and the conversion code from this site.
  • The heading font (Plus Jakarta Sans) from Google Fonts. The body font (Inter) is hosted on this site.
  • For HEIC and MP3 conversion only: one extra component from jsDelivr (a CDN). Only program code is downloaded; your file is not sent anywhere.

How to check it yourself

Open your browser's developer tools (Network tab) while converting: you will not see your file being sent out.

Connection

The site is served over HTTPS.
