How to Prepare Photos and Documents for Online Applications

Published November 5, 2026 · Ubahin Team

Applications for CPNS (Indonesian civil service), scholarships, schools, and jobs usually ask for files in a specific format and under a size limit. Files are often rejected not because of their content, but because the file is too large or in the wrong format. Here is a preparation order that helps.

1. Read the portal's requirements carefully

Every portal is different. Note the format requested (JPG, PNG, or PDF), the size limit per file (for example 100 KB, 200 KB, or 500 KB), and the photo size if there is one. The portal's official requirements always come first, not this guide.

2. Prepare your ID photo

Use a photo with a clearly visible face and a background that meets the requirements. Crop it to the requested size with ID Photo 3×4 for Applications, then shrink it if needed with Compress Photo to 200 KB.

3. Scan your documents properly

Photograph documents in bright light, held straight, with all edges visible. Use enough resolution that the text is readable, but there is no need to overdo it because the file will be shrunk again.

4. Combine and shrink the PDF

If the portal asks for a single PDF, combine the document photos with JPG to PDF and set the order. If the size is still over the limit, use Compress PDF starting at the Medium level.

5. Check before uploading

  • Open the final file and make sure the text is still readable.
  • Check the file size in the file properties.
  • Give the file a clear name, such as ktp-name.pdf, without spaces or odd characters if the portal rejects them.

About privacy

Identity documents are sensitive. Ubahin's tools process them in your browser and do not upload them to our servers. Still, be careful: only use official portals to submit your files.

The most common mistakes that get files rejected

  • File size over the limit. Always check the final size in the file properties, not an estimate.
  • Wrong format. A portal that asks for JPG does not always accept PNG or HEIC. Photos from an iPhone are often in HEIC format, so convert them first with HEIC to JPG.
  • Cropped or tilted documents. Make sure all four edges of the paper are visible.
  • Blurry photos. Shrinking the file too much makes the text unreadable. Leave a little room under the size limit.
  • Problem file names. Some systems reject spaces, parentheses, or special characters.

Example workflow for one application

Say a portal asks for an ID photo of at most 200 KB and one documents PDF of at most 500 KB. Crop the photo to the requested size, compress it to under 200 KB, then combine the scans of your KTP, diploma (ijazah), and transcript into one PDF. Check its size; if it is over 500 KB, compress the PDF or shrink the photos first. Finally, reopen the final file and make sure all pages are in order.

Keep tidy copies

Make a dedicated folder for applications and keep both the original versions and the shrunk versions. That way, if another portal asks for a different size, you just reprocess from the original file, not from the earlier compressed result.
