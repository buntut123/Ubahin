How to Enlarge or Shrink a Photo Without It Looking Blurry

Published November 5, 2026 · Ubahin Team

Resizing a photo is one of the most common jobs, but the result is often disappointing: the photo turns blurry or pixelated. The cause is almost always the same, and it can be avoided.

Shrinking is safe, enlarging is not

When a photo is shrunk, some detail is thrown away and the result stays sharp. When it is enlarged, the program has to guess new pixels, so no detail is added and the image looks soft. That is why you should always start from the original, highest-resolution photo you have.

Choose the right way to set the size

  • Percent: good for shrinking all photos by the same ratio.
  • Width or height: good when a portal specifies one side, for example a width of 1080 pixels.
  • Fit in box: keeps the whole image and does not exceed the maximum width and height.
  • Exact size: produces the exact dimensions by cropping the edges.

Steps

  1. Open Resize Image and choose a photo.
  2. Choose how to set the size, then enter the numbers.
  3. Tap process and check the dimensions of the result.
  4. If you need to reduce the file size further, continue with Compress Image.

Only once

Every time a photo is saved again as a JPG, its quality drops slightly. Avoid going back and forth between sizes and formats; do it once from the original file.
