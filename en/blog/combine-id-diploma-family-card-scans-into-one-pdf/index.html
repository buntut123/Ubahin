How to Combine Scans of Your KTP, Ijazah, and KK into One PDF

Published November 5, 2026 · Ubahin Team

Many forms offer only one upload field for all your files. The solution is to combine all the documents into a single PDF in a clear order.

If your documents are still photos

  1. Open JPG to PDF and select all the document photos at once.
  2. Set the order with the arrow buttons, for example KTP (Indonesian ID card), KK (Indonesian family card), then ijazah (diploma).
  3. Choose A4 page size for a tidy look, or Fit to image to avoid empty space.
  4. Tap Create PDF and download the result.

If your documents are already several PDFs

Use Merge PDF, select all the files, set their order, then merge them.

Make it smaller if needed

A file combined from many photos can be large. Shrink it with Compress PDF. Alternatively, shrink each photo first with Compress Image before combining, so you have better control over the quality of each page.

Tips for a neat, easy-to-read file

  • Photograph documents upright and straight, with even lighting.
  • Make sure all edges of the document are in the frame and the text is readable.
  • Arrange the documents in the order the portal's requirements list them.
  • Give the file a clear name.

File security

ID documents are highly sensitive. Everything in Ubahin runs in your browser and your files are not sent to our servers. Keep the result somewhere safe and delete it when you no longer need it.

Deciding the order of the documents

A consistent order makes things easier for the staff who review your files. If the portal does not specify an order, a common pattern is identity first (KTP and KK), then education documents (ijazah and transcript), then other supporting documents. Always follow the order the portal sets if there is one.

Page size: A4 or fit to image?

The A4 option puts each photo on a standard-size page, so the PDF looks uniform and is easy to print. The Fit to image option makes each page the same size as its photo, which suits documents you want shown as they are, with no empty margins. For administrative files, A4 is usually neater.

Frequently asked questions

Can I mix photos and PDFs? The JPG to PDF tool accepts images, while Merge PDF accepts PDFs. Convert the images to PDF first, then combine everything with Merge PDF.

What is the maximum number of photos? There is no fixed limit other than your device's memory. For dozens of high-resolution photos, shrink the photos first.

What if a page is in the wrong order? Repeat with the correct order, or move and remove pages with Split PDF and Delete PDF Pages.
