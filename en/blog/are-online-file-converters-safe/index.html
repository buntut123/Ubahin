Are Online File Converters Safe? How to Check Your File Privacy

Published November 2, 2026 · Ubahin Team

Documents such as a KTP (Indonesian ID card), an ijazah (diploma), or a contract often need to be converted or shrunk. Many converter sites work by uploading your file to their servers. That means a copy of your file ends up on someone else's computer, even if it is usually deleted after a few hours.

Two ways converter sites work

  • Processed on a server. The file is uploaded, processed, and then the result is downloaded. This suits heavy conversions, but your file leaves your device.
  • Processed in the browser. The program runs on your device and the file is not sent anywhere. This is the approach Ubahin uses for all of its tools.

How to check for yourself

  1. Open the converter site on a computer with Chrome or Edge.
  2. Press F12 to open developer tools, then choose the Network tab.
  3. Do your conversion as usual.
  4. Look at the list of requests. If there is a POST or PUT request carrying data about the size of your file, the file is being uploaded. With tools that process in the browser, you will not see one.

One note: some features load extra components from the internet, such as the HEIC or MP3 conversion libraries. What gets downloaded is the program code, not your file.

Other safe habits

  • Make sure the site address uses HTTPS.
  • For very sensitive documents, consider using an app on your own device.
  • Do not upload documents that do not need to be changed.
  • Keep the original file before converting.
