How to Compress a PDF to Under 500 KB

Published November 2, 2026 · Ubahin Team

Many registration portals limit PDF size, for example to 500 KB. Here are the steps that usually work best, starting with the lightest.

1. Find out why the PDF is large

A scanned or photographed PDF is usually large because each page is a high-resolution image. A PDF with plain text is generally already small.

2. Remove pages you do not need

Use Delete PDF Pages or Split PDF to keep only the pages you need.

3. Compress the PDF

Open Compress PDF and start with the Medium level. If the file is still over the limit, try Strong, then Extreme. Note that the text in the result becomes an image.

4. If the PDF was made from photos

Shrink the photos first with Compress Image (for example, a target of 200 KB per photo), then combine them with JPG to PDF.

5. Check the result

Open the final file and make sure the text is still readable before you upload it. Also check the organizer's official requirements, because size limits and formats can differ.
