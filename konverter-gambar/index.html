Tentang alat ini

Satu alat untuk semua gambar umum. Pilih format tujuan, atur kualitas, lalu unduh.

Cara menggunakan

  1. Pilih file

    Seret file ke kotak di atas atau klik untuk memilih dari perangkat.

  2. Atur pilihan

    Tentukan format atau kualitas, lalu tekan tombol proses.

  3. Unduh hasilnya

    Simpan satu per satu atau semuanya sekaligus dalam ZIP.

Kapan alat ini berguna

Gunakan konverter serbaguna ini bila format asal atau tujuan Anda tidak termasuk halaman khusus, misalnya GIF, BMP, atau AVIF ke JPG, PNG, dan WEBP.

Tips dan kesalahan umum

  • Pilih format tujuan sesuai kebutuhan: JPG untuk foto, PNG untuk gambar tajam atau transparan, WEBP untuk web.
  • GIF animasi hanya diambil bingkai pertamanya.
  • Beberapa file sekaligus akan dikemas dalam satu ZIP.

Pertanyaan umum

Format apa saja yang didukung?
Masuk: JPG, PNG, WEBP, HEIC/HEIF, GIF (frame pertama), BMP, AVIF. Keluar: JPG, PNG, WEBP. Dukungan tergantung browser Anda.
Apakah file saya diunggah ke server?
Tidak. Proses konversi berjalan di browser Anda, jadi file tetap berada di perangkat. Yang diunduh hanyalah komponen program (misalnya pustaka PDF) dari situs ini; untuk HEIC dan MP3 dimuat pula satu komponen tambahan dari jsDelivr. File Anda tidak ikut terkirim.
Berapa batas ukuran file?
Batas di Ubahin adalah 200 MB per file, namun batas sebenarnya bergantung pada memori perangkat Anda. File yang sangat besar bisa membuat browser lambat atau berhenti.
Apakah gratis? Perlu daftar?
Gratis dan tanpa akun. Tidak ada watermark pada hasil.
